# Word 试卷导入规则

导入支持**两种格式**，上传后自动识别，都是「**先解析预览、再确认入库**」：
解析阶段会把问题标成 **错误（阻断导入）** 或 **警告（可导入但需确认）**，所以格式错误不会污染已有试卷。

| 格式 | 适用场景 | 答案位置 |
| --- | --- | --- |
| **A. 真实试卷格式** | 学校现成的练习卷：多个「综合题」材料 + 小题，题干末尾写题型 | 单独的「参考答案」docx |
| **B. 模板格式** | 自建题目：每题以 `【题型】` 开头 | 与题目同一文件 |

两种格式可以一次上传两份 docx：

```text
试卷.docx + 参考答案.docx   → 自动合并（文件名含「答案 / 参考 / answer」的识别为参考答案）
试卷.docx                  → 只解析试卷（客观题会缺答案，预览里会提示）
模板.docx                  → 走模板格式（答案写在题目里）
```

# A. 真实试卷格式

## A1. 文档整体结构

```text
[标题段落]                         ← 可选，取第一个非空段落，长度 ≤ 60 字
（时间60分钟，满分100分）           ← 忽略
综合题一：<材料正文…>（23分）        ← 大题：材料由本题组的小题共用
1.<题干>…（单选题，2分）
A.数据        B.信息        C.知识        D.概念
2.<题干>…（填空题，3分）
…
综合题二：<材料…>（23分）
1.<题干>…（单选题，2分）
…
【数字化资源】Python帮助小贴士      ← 附录，之后的内容全部忽略
```

- **大题标记**：`综合题一：…（23分）`，也接受 `第X大题 / 第X部分 / 第X题组`。
  材料正文会作为该大题共用的「材料」，学生端与批改台**只展示一次**，不重复写进每题题干。
  材料后面的图片、表格（如数据表、流程图）也会归到材料里。
- **题号**：`1.` `1、` `1．` `1)`，每个大题内部从 1 重新开始。
  题号可以省略（例如匹配题），系统按出现顺序推断题号，再用题号去配参考答案。
- **附录**：以 `【…】` 开头且不是题型标记的行（如 `【数字化资源】`）之后的内容全部忽略。

## A2. 题型标记（写在题干末尾的括号里）

```text
（单选题，2分）
（多选题，3 分）
（填空题，6分，每空2分）
（填空题，5分，第一空2分，第二空3分）
（选填题，2分）
（匹配题，6分，每框2分）
（编程题，6分）
```

| 写法 | 识别为 | 判分方式 |
| --- | --- | --- |
| `单选题` `单项选择` `单项选择题` | 单选题 | 全对得分 |
| `多选题` `多项选择` `多项选择题` | 多选题 | 全对得分；参考答案写「漏选1个扣X分」时按漏选扣分 |
| `判断题` | 判断题 | 对/错 |
| `填空题` | 填空题 | 逐空判分（可逐空给不同分值） |
| `选填题` | 填空题 | 同上（括号里的「选填：A/B」只是提示，不影响判分） |
| `匹配题` `连线题` | 填空题 | 每个框一个空，逐框判分 |
| `简答题` `问答题` `主观题` | 简答题 | 教师人工评分 |
| `编程题` `代码题` | 代码题 | 有测试点则跑测试点；没有则教师按参考代码评分 |

- 括号里的分值说明可写：`N分`、`每空M分`、`每框M分`、`第一空A分，第二空B分`，可组合。
- 题型标记必须出现在**题干末尾**（后面不能还有别的文字）。
- 缺题型标记时，会用参考答案推断（有代码 → 代码题；只有字母 → 选择；`对/错` → 判断；其余 → 填空），并给出提示。

## A3. 选项写法

```text
A.数据            B.信息            C.知识            D.概念     ← 一行多个（空格/制表符分隔）
A.通过扫描植物标签二维码获取植物的详细介绍                          ← 也可以每行一个
```

- 选项字母 `A`–`H` + `.`/`、`/`)`/`．`，位于行首（允许前面有少量空格）。
- 一行多个选项会按字母标记自动切分，制表符、全角空格都能作为分隔。
- 选项放在 Word 表格里也能识别。

## A4. 题干内容

- **填空位**：Word 里连续 6 个以上空格（或全角空格）会渲染成下划线空位，避免 HTML 把它们折叠掉。
- **图片、表格**：原样保留（图片以 base64 内嵌），流程图、数据表、代码截图都能正常显示。
- **代码清单**：以普通段落书写的代码会逐行保留在题干里。
- 题干末尾的 `（…分）`、`（题型，…分）` 会被剥离，不进入题干。

## A5. 参考答案 docx

```text
川沙中学信息技术综合练习卷(1)参考答案     ← 标题，忽略
综合题一（23分）                          ← 大题序号，必须和试卷一致
1.（2分）C                               ← 单选
2.（3分）85                              ← 填空（单空）
4.（6分，每空2分）                        ← 多空填空：下面逐项写
第一空：有损压缩
第二空：压缩率高/大幅节省存储空间（言之有理即给分）
第三空：画面质量损失且不可逆（言之有理即给分）
5.（3分）BCD（漏选1个扣1分）             ← 多选 + 漏选扣分
6.（6分，每框2分）                        ← 匹配题
A→②    B→①    C→③
8.（6分）参考代码如下                     ← 编程题：后面整段作为参考代码
第一种
for i in range(len(movie)):      #2分
    …
```

识别规则：

| 写法 | 含义 |
| --- | --- |
| `综合题X（N分）` | 大题归属；试卷没有大题时可以省略 |
| `N.（M分）答案` | 第 N 题的答案与分值说明 |
| `第一空：…` `第二空：…` | 逐空答案，顺序即空位顺序 |
| `A→②` | 匹配题：把 A 框填成②，按字母顺序生成逐空答案 |
| `参考代码如下` | 之后到下一题/下一大题之前的所有行都算参考代码 |
| `（漏选1个扣1分）` | 多选漏选扣分，`0.5` 也支持 |

**填空答案的多种写法**：用 `/` 分隔，例如 `kinds/data.index` 表示这个空填 `kinds` 或 `data.index` 都算对。
词内斜杠不会拆（`B/S架构` 整体作为一个答案）。

## A6. 合并与校验

- 按「**大题序号 + 本大题内题号**」配对；试卷没有大题时直接按题号配对。
- 题号省略时用出现顺序推断，仍能正确配对。
- 预览里会提示：题号对不上、分值与参考答案不一致、题干空位数量与答案空数不一致等。

## A7. 真实试卷的判分规则

| 题型 | 规则 |
| --- | --- |
| 单选 | 全对得分 |
| 多选 | 全对满分；**只是漏选**（没选错）时按「每个漏选扣 X 分」扣分；选了错误选项记 0 分。参考答案没写扣分规则时，必须完全一致才得分 |
| 判断 | 全对得分 |
| 填空 | 逐空判分，分值可用 `每空M分` / `第一空A分，第二空B分` 指定；缺省按满分平均分 |
| 填空（言之有理） | 标了「言之有理即给分」的空**不自动判分**，自动分只统计其余空，该空由教师补分，批改台会标「需人工评分」 |
| 匹配题 | 按框判分（每框一个空） |
| 简答 | 全人工评分 |
| 编程题 | 有测试点则逐点判分；无测试点则整题人工评分（参考答案即参考代码） |

填空比对会做归一化：全角转半角、折叠空白、忽略大小写；再忽略全部空白比对一次，所以
`event = "男子三级跳远"` 与 `event="男子三级跳远"` 都算对。

# B. 模板格式

## B1. 文档整体结构

```text
[标题段落]            ← 可选，取第一个非空段落，长度 ≤ 60 字
[使用说明 / 任意前言]  ← 忽略
【单选】1. ……（10分）  ← 第一题开始
……
【代码】6. ……（40分）
```

- 题目之间没有分隔符，**遇到下一个 `【题型】` 就结束上一题**。
- 标题只用于导入预览时展示，不会覆盖考试名称（考试名称在系统里填写）。
- 页眉页脚、封面、说明性文字都会被忽略。

## B2. 题型标记

| 写法 | 识别为 |
| --- | --- |
| `【单选】` `[单选]` `【单选题】` `【单项选择题】` `【单项选择】` | 单选题 |
| `【多选】` `【多选题】` `【多项选择】` `【多项选择题】` | 多选题 |
| `【判断】` `【判断题】` | 判断题 |
| `【填空】` `【填空题】` | 填空题 |
| `【简答】` `【简答题】` `【问答】` `【问答题】` `【主观题】` | 简答题 |
| `【代码】` `【代码题】` `【编程】` `【编程题】` | 代码题 |

- 方括号可用全角 `【】` 或半角 `[]`。
- 题号可以写在方括号前（`1. 【单选】……`）或后（`【单选】1. ……`），都会被剥掉。
- 题型标记必须出现在段落**前 24 个字符内**，否则不认为是新题。

## B3. 通用字段

| 字段 | 写法 | 必填 | 说明 |
| --- | --- | --- | --- |
| 分值 | 题干末尾 `（10分）` / `(10分)` / 单独一行 `分值：10` | 否 | 缺省时按题型默认值（单选 5、多选 5、判断 3、填空 5、简答 10、代码 20）并给出警告 |
| 答案 | `答案：B` | 客观题必填 | 也接受 `参考答案：` |
| 解析 | `解析：……` | 否 | 发布成绩后学生可见 |
| 选项 | `A. 内容` 每行一个，或一行多个 | 选择题必填（≥2） | 支持 `A.` `A、` `A)` `A．` |

> 字段名后的冒号支持全角 `：` 与半角 `:`。

## B4. 各题型写法

### B4.1 单选题

```text
【单选】1. 下列存储器中，断电后数据会丢失的是（　　）（10分）
A. ROM
B. RAM
C. 硬盘
D. U 盘
答案：B
解析：RAM 属于易失性存储器。
```

- 答案只允许一个字母；写成多个会报错「单选题答案只能有一个」。
- 答案字母必须在选项范围内，否则报错。

### B4.2 多选题

```text
【多选】2. 下列属于输入设备的有（　　）（15分）
A. 键盘　　B. 显示器　　C. 鼠标　　D. 扫描仪
答案：A,C,D
```

- 答案支持 `A,C,D`、`A、C、D`、`ACD` 三种写法。
- 判分规则：与正确集合完全一致才得分（模板格式不写漏选规则）。

### B4.3 判断题

```text
【判断】3. 算法必须在有穷步内结束。（5分）
答案：对
```

- 正确：`对` `正确` `√` `✓` `是` `真` `T` `TRUE` `Y` `1`
- 错误：`错` `错误` `×` `✗` `否` `假` `F` `FALSE` `N` `0`

### B4.4 填空题

```text
【填空】4. 1KB = ______ 字节，1MB = ______ KB。（10分）
答案：1024 | 1024B || 1024
```

- `||` 分隔「空」，`|` 分隔「同一个空的可接受写法」。
- 上面例子是 **2 个空**：
  - 第 1 空接受 `1024` 或 `1024B`
  - 第 2 空接受 `1024`
- 分值按空平均分配（10 分 / 2 空 = 每空 5 分）。
- 比对前会做归一化：全角转半角、去首尾空白、折叠空格、忽略大小写。

### B4.5 简答题

```text
【简答】5. 简述什么是死循环，并说明后果。（20分）
参考答案：程序在满足退出条件前反复执行同一段代码，无法自行结束……
```

- 不自动判分，必须教师在批改台给分。
- 没有参考答案只给警告，不阻断导入。

### B4.6 代码题

```text
【代码】6. 求 1 到 n 的累加和。（40分）
语言：Python
说明：读入一个正整数 n，输出 1 + 2 + … + n 的结果。
样例输入：10
样例输出：55
测试点：
输入=7 | 输出=28 | 10分 | 公开
输入=1 | 输出=1 | 10分
输入=100000 | 输出=5000050000 | 20分
```

| 字段 | 说明 |
| --- | --- |
| `语言：` | `Python` / `JavaScript`（支持逗号分隔多个）；缺省 Python |
| `说明：` | 追加到题干，用于补充题意 |
| `样例输入：` / `样例输出：` | 生成一个「公开且不计分」的样例，学生端可见 |
| `测试点：` | 其后每一行一个测试点，直到下一题 |

**测试点语法**

```text
输入=<stdin> | 输出=<stdout> | <分值>分 | 公开
```

- 分隔符：`|` 或 `｜`，两侧空格随意。
- `输入=` / `输出=` 也可以写成 `输入：` / `输出：`。
- 分值可省略；省略的分值按「题目剩余分 / 未标注用例数」平均分配。
- `公开`（或 `可见`、`样例`）表示学生端可见该用例的输入输出；不写就是隐藏用例。
- 多行输入用 `\n` 转义：`输入=3\n1 2 3 | 输出=6 | 10分`。

**判分**：每个测试点独立运行、独立给分；超时（默认 2000ms）、非零退出、输出不符该点记 0 分，其余点照常给分（部分分）。

# C. 解析细节

## C1. 选项识别

- 选项必须以 `A`–`H` 开头，且位于行首（允许前面有少量空格）。
- 一行多个选项会按字母标记自动切分：`A. 键盘 B. 显示器` → 两个选项。
- 选项放在 Word 表格里也能识别（表格每格视为一行）。

## C2. 题干保留规则

- 普通段落原样保留（表格/图片不拆散）。
- 识别为「字段行 / 选项行 / 测试点行 / 大题标记」的段落不进入题干。
- 题干末尾的 `（10分）`、`（题型，2分）` 会被剥离并作为分值/题型。

## C3. 分值优先级

1. 参考答案里的 `N分`（仅在试卷没写时使用）
2. 题干末尾 `（N分）` 或 `（题型，N分…）`
3. `分值：N` 字段（模板格式）
4. 题型默认值（并给出警告）

# D. 报错对照

| 提示 | 级别 | 原因 / 处理 |
| --- | --- | --- |
| `题干为空` | 错误 | 题型标记后没有内容 |
| `选项少于 2 个` | 错误 | 选择题选项未按 `A.` 格式书写 |
| `缺少答案（格式：答案：B 或 答案：A,C）` | 错误 | 没有答案行（模板格式） |
| `缺少答案（参考答案中该题没有选项字母）` | 错误 | 参考答案里该题没有写字母 |
| `答案 BCD 不在选项范围内` | 错误 | 字母写错或选项缺失 |
| `单选题答案只能有一个，参考答案写的是 AB` | 错误 | 单选写了多个字母 |
| `判断题答案应为 对/错` | 错误 | 用了其他写法 |
| `缺少答案（参考答案中该题没有内容）` | 错误 | 参考答案里该题是空的 |
| `参考答案里没有找到对应题号` | 错误 / 警告 | 试卷题号与参考答案对不上（代码题/简答题只警告） |
| `题干里有 3 处空位，参考答案给了 2 个空` | 警告 | 空位数与答案数不一致，检查是否漏写 |
| `逐空分值合计 5 分，与题目分值 6 分不一致` | 警告 | 检查 `每空M分` / `第一空A分` |
| `试卷标注 2 分，参考答案标注 3 分，以试卷为准` | 警告 | 两份文件分值不一致 |
| `题干缺少题型标记，已按参考答案推断题型` | 警告 | 建议在题干末尾补 `（单选题，2分）` |
| `未识别到分值，按 N 分处理` | 警告 | 忘了写分值 |
| `代码题缺少测试点` | 错误 | 模板格式的代码题 `测试点：` 下没有可识别用例 |
| `测试点分值合计 X 超过题目分值 Y` | 警告 | 检查分值分配 |
| `测试点格式无法识别：…` | 警告 | 该行包含「输入/输出」但不是合法用例 |
| `全卷合计 X 分（不是 100 分…）` | 提示 | 仅提示，不影响导入 |
| `未识别到任何题目…` | 提示 | 没有题型标记（模板格式）或没有「综合题 + 题型标记」（真实卷） |

**有「错误」时禁止确认导入**；警告不阻断，但建议先修正。

# E. 自检

改完模板或换成新卷子后，可以不上传、直接用命令行验证解析结果：

```bash
# 模板格式
pnpm exec tsx scripts/test-import.ts templates/题目模板.docx

# 真实试卷 + 参考答案
pnpm exec tsx scripts/test-import.ts \
  "templates/川沙中学信息技术综合练习卷(1)(1).docx" \
  "templates/川沙中学信息技术综合练习卷(1)（参考答案）(1).docx"
```

输出会按大题分组列出每题的题干、选项、答案、逐空分值、测试点与问题列表。

完整链路（导入 → 发布 → 作答 → 自动判分 → 成绩页）也可以一条命令验证：

